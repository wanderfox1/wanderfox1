### About me

I build fast, polished interfaces — currently deep in **Web3 / crypto products**. React and TypeScript are home base; everything else on this page is a tool I reach for when the product needs it.

<br/>

---

<br/>

### 🧩 Architecture & State

- **Feature-Sliced Design** as the default architecture on every serious project
- **Redux Toolkit**, including **RTK Query** and **Async Thunk** for complex data flows
- **TanStack Query** for server state, with a habit of tuning it for fewer, smarter requests
- **TanStack Table** and other Tanstack-family components for data-heavy UIs
- Comfortable working across `localStorage`, cookies, and session storage for persistence and auth state
- **JWT auth flows** — access/refresh token rotation, protected routes, session polling

<br/>

### 🎨 UI, Theming & Component Systems

- Shipped production UI with **Radix UI**, **MUI**, **Ant Design**, and in-house UI-kits — picking the right one for the constraints of the project, not just the one I like
- Dark/light theme support as a default, persisted to storage rather than bolted on later
- Skeleton loading states and lazy loading (`React.lazy`, route-based splitting) as standard practice
- i18n support built in from the start, not retrofitted
- Linting and code-quality tooling set up and enforced across teams

<br/>

### ✨ Animation & Interaction

- Complex animation work, including **parallax** effects
- **Framer Motion**, **GSAP**, **React Spring** for interaction and page transitions
- **Lottie** and **Lottie Lab** for motion assets, from integration to fine-tuning timing
- Custom charting on top of **Recharts**, customized well past the defaults

<br/>

### ⚡ Performance & Tooling

- `useMemo` / `useCallback` used deliberately, not defensively — plus custom hooks like `useDebounce`
- Render optimization and cutting redundant API calls as a recurring focus, not a one-off cleanup
- Analytics and tracking integration — **Yandex Metrics**, third-party widgets (e.g. Umnico)
- Workflow: **Scrum / Agile**, task tracking in **Jira** and **Kaiten**, regular code review — both giving and receiving

<br/>

---

<br/>

### 💼 What I build

- **CRM / Backoffice** systems for crypto platforms
- **Swap & exchange** interfaces — wallet connections, on-chain transaction flows (Ethereum, Tron)
- **Landing pages** — from analytics dashboards to marketing sites
- Wallet integrations via **RainbowKit**, **wagmi**, **viem**, **TronWeb**

Building out a Node.js backend on the side — `Express`, `Prisma`, `PostgreSQL` — mainly to round out the picture on the API side of things I already build the frontend for.
